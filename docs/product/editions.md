# 版本对照：社区版 vs 商业源码版

> 本页回答采购与法务最常问的问题：「我免费拿到的是什么，付费买到的是什么」。
>
> **边界原则**：社区版（Apache-2.0）提供完整的治理网关能力，**不藏关键功能**；商业源码版售卖的是**企业集成与合规增强模块**的闭源源码 + 年度授权，而非对社区版已有功能的收费墙。

## 一、一句话对比

| | 社区版 | 商业源码版 |
|---|---|---|
| 授权方式 | Apache-2.0 开源，GitHub 公开 | 年度商业源码许可（专享，禁止再分发） |
| 包含范围 | 下表标 ✅ 的全部能力 | 社区版全部 + 下表标 🧭 的闭源治理模块 |
| 适合谁 | 技术团队自建、评估试用 | 需要企业身份集成、合规审计、SLA 保障的政企客户 |
| 获取方式 | Docker 一条命令自建 | 联系获取报价与许可协议 |

## 三、法务与采购常见问题

**Q1：年度授权到期后会怎样？**
已交付版本的源码与部署可继续使用（授权条款不回收已交付物），但失去后续小版本升级与官方支持通道。

**Q2：商业版源码可以再分发吗？**
不可以。商业源码许可协议包含禁止再分发、禁止转售、禁止竞业使用条款，核心治理模块含 License 校验与服务端绑定。

**Q3：社区版会不会「藏功能逼付费」？**
不会。社区版持续全量迭代网关内核与控制台能力（开源获客是商业模式的地基）；商业版只做**增量**的企业集成与合规模块，不回收社区版已有功能。

**Q4：上游授权是否干净？**
Trunkline 基于 JAiRouter（Apache-2.0）二次开发，全栈保持 Apache-2.0 干净，保留上游版权声明与署名（Attribution），不存在 AGPL 传染风险，增量代码可申请软著。

**Q5：可以私有化部署吗？**
可以。私有化部署是两种版本共同的默认形态；本项目不提供运营型 SaaS，不售 token。
