# My Keys

> Every key you own, and the models each one can use.

## What this page does

A key is your access pass to the company AI service. Without one, no AI tool can connect. This page lists your keys, the models each key may use, this month usage, and expiry dates.

## When you need it

- Getting a key for the first time
- Setting up a new computer or tool
- Checking which models a key allows
- Checking whether a key is about to expire

## What is on this page

| What you see | What it means |
| --- | --- |
| Purpose | What this key is for, e.g. "proposals" or "coding" |
| Key | Shown masked; use the copy icon on the row to retrieve the full key |
| Allowed virtual models | The model names this key may use; anything not listed will fail |
| Used this month / Expires / Status | Usage, validity, and status such as Active, Expires in 30 days, Expired, Never expires |
| What is a key? What is a virtual model? | A short explanation card at the bottom of the page |

## Common tasks

**Request your first key**

1. Click "Request a new key"
2. Describe what you need it for so the administrator can pick the right models
3. Click "Copy request" and send that text to your administrator
4. Refresh the page once the key is created

**Retrieve the full key**

1. Find the key row
2. Click the copy icon on that row
3. Paste it into your AI tool

**Check a model**

1. Read the "Allowed virtual models" column
2. If the name is missing, choose another or ask for access

## If something goes wrong

**Nothing happens after I submit a request**

There is no online approval flow yet. The button copies a ready-made request for you to send to your administrator.

**I shared my key or suspect a leak**

Ask your administrator to disable it and issue a new one immediately.

**Status says Expired**

Ask your administrator to renew it or create a new key.

## Still stuck?

Give your account name and the key purpose to your administrator. **Never paste a full key into a chat or a ticket**.
