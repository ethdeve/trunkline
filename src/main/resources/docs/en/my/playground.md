# Playground

> Try one message here without installing anything.

## What this page does

Playground is a chat box in your browser. Pick one of your models, send a message and see whether you get a reply. Confirming it here first saves a lot of back-and-forth when configuring your own tools.

## When you need it

- You just received a key and want to confirm it works
- A tool reports an error and you want to know whether the service itself is fine
- You want to try image generation

## What is on this page

| What you see | What it means |
| --- | --- |
| Chat | Pick a model, type, send; Enter sends, Shift + Enter adds a new line |
| Image / Generate · Edit | Write a prompt, choose size and quality, generate or edit an image |
| Semantic search / Rerank / Voice | Only visible to operations staff and administrators |
| Parameters | Collapsed advanced settings; normally leave them alone |
| New chat / Clear | Start over or clear the current conversation |

## Common tasks

**Try one message**

1. Pick a virtual model
2. Type "Hello" and send
3. A reply means it works

**Generate an image**

1. Switch to Image → Generate
2. Write a prompt, choose size and count
3. Click Generate

**Debug a failing tool**

1. Try the same model here first
2. If it works here, the address, key or model name in your tool is wrong
3. If it fails here too, send the error text to your administrator

## If something goes wrong

**"Please select a model first"**

Pick a model at the top left before sending.

**"You have no available models"**

Your administrator has not enabled any model for you yet.

**I cannot see Voice or Semantic search**

Those tabs are limited to operations staff and administrators.

## Still stuck?

Tell your administrator the model name, what you sent, and the exact error text.
