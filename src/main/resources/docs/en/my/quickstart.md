# Quick Start

> Three steps to connect your favourite AI tool.

## What this page does

Everything you need is prepared here: the company address, your key, which field to fill in common tools, and a ready-made command to verify the connection. Work from top to bottom.

## When you need it

- First time setting up Cherry Studio, Cursor or ChatBox
- Setting up a new computer
- A tool keeps failing and you want to re-check every field

## What is on this page

| What you see | What it means |
| --- | --- |
| Step 1 · Copy the address | The company access address |
| Step 2 · Get your key | Copy the full key from My Keys |
| Step 3 · Fill it into your tool | Setup cards for Cherry Studio, Cursor and ChatBox / NextChat |
| Verify it works | A ready-made command; a text response means it is connected |
| Scan to take the setup with you | The QR code carries the address and model name only, **not your key** |

## Common tasks

**You do not have a key yet**

1. The page shows a "get a key first" path
2. Tell your administrator what you want to do
3. Come back once the key is issued

**You already have a key**

1. Copy the access address
2. Copy the full key from My Keys
3. In your AI tool, put the address into API address / Base URL and the key into API Key
4. Set the model to your company virtual model name, e.g. company-chat, then save

**Verify**

1. Copy the command into a terminal
2. Replace the sample key and sample model name with your own
3. A text response means it works; alternatively try one message in Playground

## If something goes wrong

**What goes in the model field**

Use the company virtual model name shown in My Quota or My Keys. **Do not use vendor names like gpt-4o**.

**The verification command does nothing**

Make sure you replaced the sample key and model name. If Playground works, the problem is in your tool settings.

**Is my key inside the QR code**

No. It only carries the address and model name, so screenshots are safe.

## Still stuck?

Send your administrator the tool name, the address and model you entered, and the exact error text.
