# 我的密钥

> 你名下的密钥和能用的模型，都在这里。

## 这个页面是干什么的

密钥相当于你调用公司 AI 的「门卡」。没有它，任何 AI 工具都连不上公司的服务。这一页列出你名下所有密钥、每把能用哪些模型、本月用了多少、什么时候到期。

## 什么时候会用到

- 第一次接入，需要拿到密钥
- 换电脑或换工具，要重新填密钥
- 想知道这把密钥还能用哪些模型
- 快到期了想确认状态

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 用途 | 这把密钥是干什么用的，例如「写方案」「代码助手」 |
| 密钥 | 打码显示；点这一行右边的复制图标可以取回完整密钥 |
| 可用虚拟模型 | 这把密钥允许使用的模型名清单，没列出来的就调不通 |
| 本月已用 / 到期时间 / 状态 | 用量、有效期；状态有「正常 / 30天后到期 / 已过期 / 长期有效」 |
| 什么是密钥？什么是虚拟模型？ | 页面下方的说明卡，用大白话解释这两个词 |

## 常见操作

**第一次申请一把密钥**

1. 点「+ 申请新密钥」
2. 填用途，写清楚你要做什么，管理员好判断给哪些模型
3. 点「复制申请内容」，把这段现成的话发给管理员
4. 管理员建好后回来刷新页面

**取回完整密钥**

1. 在表格里找到那把密钥
2. 点这一行右边的复制图标
3. 粘贴到你的 AI 工具里

**核对能不能用某个模型**

1. 看「可用虚拟模型」这一列
2. 没有列出的模型名，换一个或找管理员开通

## 遇到问题先看这里

**申请点了之后没动静**

系统里还没有在线审批流程。「申请」的实际动作是把申请文字复制给你，你发给管理员即可。

**密钥发给别人了，或者怀疑泄露**

立刻联系管理员，让他把这把密钥停用并重新发一把。不要等。

**状态显示「已过期」**

联系管理员续期或新建一把；过期密钥不能再用。

## 还是要人帮忙？

找管理员时提供你的账号名和这把密钥的「用途」。**不要把完整密钥贴在群里或工单里**。
