# 测试场

> 不用装任何东西，先在这里试一句。

## 这个页面是干什么的

测试场就是一个网页版的对话框。选一个你能用的模型，发一句话，看有没有回复。通了再去你自己的 AI 工具里配置，能省掉很多来回排查的时间。

## 什么时候会用到

- 刚拿到密钥，想确认能不能用
- AI 工具里报错，想判断是工具没配好还是服务本身有问题
- 想试试图像生成等不同类型的能力

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 对话 | 选模型、输入内容、发送；按 Enter 发送，Shift + Enter 换行 |
| 图像 / 图像生成·编辑 | 写提示词、选尺寸和质量，生成或编辑图片 |
| 语义搜索 / 结果重排 / 语音 | 只有运维和管理员能看到，普通员工看不到是正常的 |
| 参数配置 | 折叠的高级设置，一般不用改 |
| 新对话 / 清空 | 开一段新对话，或清掉当前内容 |

## 常见操作

**试一句**

1. 点「选择模型」，选一个虚拟模型
2. 输入「你好」，发送
3. 看到回复就说明通了

**生成一张图**

1. 切到「图像」→「图像生成」
2. 写提示词，选尺寸和数量
3. 点「生成图像」

**排查工具报错**

1. 先在测试场用同一个模型试一句
2. 这里能通，问题就在工具的地址、密钥或模型名填错了
3. 这里也不通，把报错文字发给管理员

## 遇到问题先看这里

**提示「请先选择模型」**

先点左上角选一个模型，再发送。

**显示「你还没有可用的模型」**

管理员还没给你开通模型，联系管理员。

**看不到语义搜索、语音这些页签**

这些只对运维和管理员开放，普通员工只用「对话」和「图像」。

## 还是要人帮忙？

告诉管理员你选的模型名、发送的内容，以及页面上的报错文字。
