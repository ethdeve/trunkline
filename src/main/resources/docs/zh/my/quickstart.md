# 快速上手

> 三步，把公司 AI 装进你常用的工具。

## 这个页面是干什么的

这一页把接入需要的东西都准备好了：公司的接入地址、你的密钥、几种常见工具里该填哪一栏，还有一条用来验证的现成命令。照着从上往下做就行。

## 什么时候会用到

- 第一次在 Cherry Studio、Cursor、ChatBox 等工具里配置公司 AI
- 换了新电脑要重新配一遍
- 工具一直报错，想从头核对一遍

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 第 1 步 · 复制地址 | 公司的接入地址，点「复制地址」 |
| 第 2 步 · 拿到密钥 | 去「我的密钥」复制完整密钥 |
| 第 3 步 · 填到工具里 | Cherry Studio / Cursor / ChatBox·NextChat 三张配置卡，告诉你每一栏填什么 |
| 验证一下真的通了 | 一条现成命令，粘到终端执行，返回文字就说明通了 |
| 手机扫码，配置带走 | 二维码只带地址和模型名，**不含密钥**，防止截图泄露 |

## 常见操作

**还没有密钥**

1. 页面会显示「先领一把密钥」
2. 按三步提示告诉管理员你要做什么
3. 拿到密钥后回来继续往下做

**已有密钥，开始配置**

1. 复制「接入地址」
2. 到「我的密钥」复制完整密钥
3. 打开你的 AI 工具，把地址填到 API 地址 / Base URL，密钥填到 API Key
4. 模型名填成公司给你的虚拟模型名（例如 company-chat），保存

**验证是不是真的通了**

1. 点「复制命令」，粘到终端
2. 把命令里的「你的密钥」和示例模型名换成你自己的再执行
3. 看到返回文字即成功；也可以点「也可以直接在测试场试一句 →」

## 遇到问题先看这里

**工具里 model 那一栏填什么**

填公司给的虚拟模型名，在「我的额度」「我的密钥」里都能看到。**不要填 gpt-4o 这类厂商原名**。

**验证命令没反应**

先确认命令里的示例密钥和示例模型名已经换成你自己的；仍然不行就去测试场试一句，那里能通就说明是工具配置问题。

**二维码里有没有密钥**

没有。二维码只带地址和模型名，可以放心扫码。

## 还是要人帮忙？

把工具名称、你填的地址和模型名、以及报错原文一起发给管理员。
