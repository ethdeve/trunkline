# 我的额度

> 这个月我用了多少、还剩多少，一眼看完。

## 这个页面是干什么的

打开控制台默认就是这一页。它只显示**你自己**的数据，不会显示别人的。上面是额度和密钥，中间是本月用了几次、能用哪些模型，下面是每天花了多少钱的曲线和最近几次使用记录。

## 什么时候会用到

- 想知道这个月还剩多少额度
- 想看看自己能用哪些模型
- 发现自己调不通，先来确认密钥和模型是不是齐的
- 想看看最近几次调用成功没有

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 本月已用额度 | 一条进度条，显示已用和剩余；每月 1 号重新计算 |
| 我的接入密钥 | 你名下的密钥；这里「复制」拿到的是打码后的样子，不能用来调用 |
| 我能用的模型 | 公司允许你使用的虚拟模型名，填到 AI 工具里就用这些名字 |
| 本月每天花了多少钱 | 按天看花费走势 |
| 最近几次使用 | 时间、用了哪个模型、花了多少、成功还是失败 |

## 常见操作

**看看自己还剩多少**

1. 打开本页，看「本月已用额度」的进度条
2. 想看明细，点「查看怎么花的 →」去我的账单

**第一次用，什么都没有**

1. 点「去领一个密钥」到我的密钥页
2. 按页面说明把申请内容发给管理员
3. 拿到密钥后回来刷新

**想先试一下能不能用**

1. 点「去测试场试试」
2. 选一个模型，发一句话，看有没有回复

## 遇到问题先看这里

**进度条是空的，或者金额是 0**

通常是本月还没调用过，或者管理员还没给模型配单价。单价没配好时花费显示 ¥0，账单页会有提示；这不影响能不能用。

**「申请更多额度」点了没反应**

这个按钮目前只把申请内容整理好，系统里还没接入在线审批。请直接联系管理员帮你调整额度。

**复制出来的密钥用不了**

这一页复制的是打码串，只用来核对是哪一把。完整密钥只在创建时显示一次，需要到「我的密钥」页点那一行右边的复制图标取回。

## 还是要人帮忙？

联系管理员时，告诉他你的账号名、想用的模型名，以及页面上看到的提示文字。
