# 账号管理

> 谁能登录控制台、每个人是什么角色。

## 这个页面是干什么的

只有管理员能进这一页。这里创建员工账号、分配角色、填部门（部门用于「团队用量」按部门汇总），也可以停用账号或批量导入。

## 什么时候会用到

- 新员工入职要开账号
- 有人岗位变了，要改角色
- 有人离职，要停用账号
- 要按部门统计用量，先把部门补齐

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 总账户数 / 已启用 / 已禁用 / 管理员 | 四个统计数字 |
| 用户名 / 姓名 / 部门 / 角色 / 状态 / 创建时间 | 账户列表；角色有管理员、运维、用户、访客 |
| 创建账户 / 批量导入 / 刷新 / 搜索 | 常用操作 |
| 状态开关 | 一键停用 / 启用，不用删账号 |

## 常见操作

**新建一个账号**

1. 点「创建账户」
2. 填用户名、姓名、部门，选角色、设密码
3. 点「确定」

**停用某人**

1. 在列表里找到他
2. 拨「状态」开关，变为已禁用
3. 比删除安全，随时可恢复

**按部门统计之前**

1. 逐个把「部门」补齐
2. 团队用量页才能按部门汇总

## 遇到问题先看这里

**编辑时密码留空**

表示不修改密码，其他照常保存。

**删不掉默认管理员**

系统保护，默认管理员账号不可删除。

**角色怎么选**

用户＝只用自己的额度、密钥、测试场；运维＝还能管团队用量、接入、密钥、观测；管理员＝全部，含账号与系统设置。

## 还是要人帮忙？

账号问题联系管理员，提供用户名和你在页面上看到的提示。
