# 路由规则

> 满足什么条件，就把请求交给哪个模型。

## 这个页面是干什么的

这里可以写一组「如果……就……」的规则，比如「来自某个部门的请求走便宜模型」。规则从上往下按顺序匹配，**第一条命中就生效**，后面的不再看。不配规则就按默认方式分配，大多数公司其实用不上这一页。

## 什么时候会用到

- 想让不同部门或不同用途走不同模型
- 想按比例把一部分请求分到新模型上试水
- 想临时把某类请求指向指定模型

## 页面上有什么

| 你看到的东西 | 是什么意思 |
| --- | --- |
| 先看哪条（优先级） | 数字越大越先匹配 |
| 名称 / 条件 / 动作 | 条件可以是模型分类、模型名、请求头、来源 IP、按比例；动作可以是重写模型、锁定实例、切换接入方式、分流方式、限制速度、按标签路由 |
| 本月命中 | 这条规则被用了多少次 |
| 从模板创建 / 模拟测试 / 新增规则 | 常用按钮，模拟测试不用保存就能看结果 |

## 常见操作

**新增一条**

1. 点「新增规则」
2. 填名称，「添加条件」
3. 选动作，保存
4. 用「模拟测试」填一个示例请求，看命中哪条

**验证是否命中**

1. 点「模拟测试」
2. 填示例请求
3. 查看结果；不需要先保存

**临时停用**

1. 点该行「停用」，规则保留但不生效

## 遇到问题先看这里

**规则没生效**

检查是不是被上面优先级更高的规则先命中了；再用「模拟测试」看实际命中哪条。

**找不到「响应缓存」页签**

这个功能本期未开放，页面只有「分配规则」。

## 还是要人帮忙？

把规则名称、条件、期望结果，以及「模拟测试」的结果发给管理员。
